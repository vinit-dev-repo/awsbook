# 02 - Getting started with an account

The files the chapter **02 - Getting started with an account** of the AWS tutorial writes in its command blocks, copied byte for byte from the chapter. The blocks write them into the work folder `~/awsbook-ch02`; cloning this folder there gives the same files. The chapter explains every line; the table says where each file is written: the section heading and the line where the file's text starts.

## What this chapter teaches

- Say what an AWS account holds, and tell the root user from an IAM user
- Sign up on the public form, choose between the Free plan and the Paid plan, and deal with a slow activation
- Protect the root user with MFA, and set up this book's own IAM user, `awsbook`, with a profile for the CLI
- Find your way around the console: the home page, the services menu, the search box, Regions and Global services, and the settings
- Install the AWS CLI at the pinned version, read its settings, and check which user it runs as
- Make a cost budget and a billing alarm, and say when to use each
- Write, deploy and delete a first CloudFormation stack, then clean up so that nothing is left behind
