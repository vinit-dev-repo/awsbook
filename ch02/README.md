# 02 - An account, its protection and the tools; A budget, a first stack and cleaning up

The blocks write them into the work folder `~/awsbook-ch02`; cloning this folder there gives the same files. ## What this chapter teaches

- What an AWS account holds, and how the root user differs from an IAM user
- How to sign up on the public form, choose the Free plan or the Paid plan, and handle a slow activation
- How to protect the root user with MFA, and set up this book's own IAM user `awsbook` with a CLI profile
- How to find your way around the console: the home page, the services menu, search, Regions, Global services and settings
- How to install the AWS CLI at the pinned version, read its settings, and check which user it runs as
- How to make a cost budget and a billing alarm, and when to use each
- How to write, deploy, read back and delete a first CloudFormation stack
- How to clean up so that nothing is left behind, and check it with one count
