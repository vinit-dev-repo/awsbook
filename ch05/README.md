## What this chapter teaches

- Read the AWS catalogue by category, on the products page and in the public SSM parameters
- Find, for every service of the catalogue, the chapter of this book that teaches it
- Tell a service code from a product name, and count the codes with the CLI
- Sort the networking services into four groups: foundations, application, edge and hybrid
- Make an SES email identity, say why mail needs verification, and say what the sandbox limits
- Make an Amplify Hosting app and a branch, and tell an app from a branch from a deployment
- Make an IoT thing and an IoT policy, read the data endpoint, and name the certificate that joins them
- Make a Service Catalog portfolio and a License Manager license configuration, and say what each one is for
- Build the same resources as one CloudFormation stack that grows by one resource in each section
- Read the Amazon Braket device list, and count what the account holds in services that cost money or that the book's user may not use
- Name the media, game, people and search services, and what each one is for
- Read the three General Reference tables, and name the services that reached the end of support with the dates the AWS pages give
- Delete the chapter's stack, then count that nothing is left
