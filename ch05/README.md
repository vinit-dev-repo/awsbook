# 05 - The wider AWS service catalogue

The files the chapter **05 - The wider AWS service catalogue** of the AWS tutorial writes in its command blocks, copied byte for byte from the chapter. The blocks write them into the work folder `~/awsbook-ch05`; cloning this folder there gives the same files. The chapter explains every line; the table says where each file is written: the section heading and the line where the file's text starts.

## What this chapter teaches

- Read the AWS catalogue by category, on the products page and in the public SSM parameters, and find the chapter that teaches each service
- Make an SES email identity, say why mail needs verification, and say what the sandbox limits
- Make an Amplify Hosting app and a branch, and tell an app from a branch from a deployment
- Make an IoT thing and an IoT policy, read the data endpoint, and name the certificate that joins them
- Make a Service Catalog portfolio and a License Manager license configuration, and say what each one is for
- Read the Amazon Braket device list, and count what the account holds in services that cost money or that the book's user may not use
- Name the services that reached the end of support, with the dates the AWS pages give
- Build the same resources as one CloudFormation stack, then delete everything and count that nothing is left
